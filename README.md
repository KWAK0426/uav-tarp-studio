# UAV Tarp Studio

Windows x64용 MicaSense RedEdge-MX Dual 타프 반사도 처리 앱입니다. 로컬 처리는 Codex와 인터넷 연결 없이 동작합니다.

[최신 설치 ZIP](https://github.com/KWAK0426/uav-tarp-studio/releases/latest/download/UAV-Tarp-Studio-Windows.zip) · [배포 내역](https://github.com/KWAK0426/uav-tarp-studio/releases)

## 시작

1. ZIP 전체를 쓰기 가능한 폴더에 풀고 `UAV_Studio.exe`를 실행합니다. 호환 Python 환경은 재사용합니다.
2. 한 회차의 원영상과 결과 폴더를 지정하고 자동 점검 결과를 확인합니다.
3. 01 자료 연결에서 Ed 시간대를 확인하고 **원자료 폴더 → 자동 연결**을 누릅니다. RAMSES 하위 `.dat`를 날짜별 CSV로 변환하고 현재 촬영일만 연결합니다. 기존 CSV도 선택할 수 있습니다.
4. 원영상을 스캔·등록하고, 02에서 해당 회차 Photos로 위치 확인용 모자이크를 연결합니다. 타프 위치와 겹치는 영상의 포함 여부를 확인합니다.
5. 03의 자동 ROI·trim·그림자 제외 제안을 확인합니다. 정합과 전체 타프 경계 포화 검사를 통과하고 기준·독립 검증 타프가 충분한 밴드만 처리합니다.
6. 05에서 선택 영상의 정상 밴드 반사도를 산출하고 독립 검증 오차를 확인합니다. 전체 촬영분은 **검증 결과 승인 · 전체 처리 허용 → 승인한 밴드로 전체 반사도 산출**로 진행합니다.

다음에 누를 버튼은 붉은 테두리로 표시합니다. 진행 중에는 진행률과 현재 단계의 예상 시간을 표시합니다. 반사도 TIFF는 실행별 `Reflectance` 폴더 바로 아래에 저장합니다. 전체 처리는 원영상·Ed·승인 근거·여유 공간 검사를 통과해야 시작합니다.

## 타프 세트 입력과 창 위치

02의 타프 ID에 `PNU_s`를 입력하면 1 m 검정·회색·흰색 3장으로 인식합니다. `PNU_s, PNU_s_56`은 세트에 흰색 1장을 추가한 총 4장입니다. 추가 타프는 `PNU_s_56__2`처럼 별도 ROI ID로 관리하고 원래 실측표를 적용합니다. 같은 반사도 종류의 여러 장을 서로 다른 검증 종류로 중복 계산하지 않습니다. 입력 아래에 실제 ID와 장수를 표시합니다.

새 Tk 보조 창은 스튜디오 본창 가운데에 열립니다. 사용자가 옮긴 창을 다시 표시할 때는 위치를 유지합니다.

## 내장 교정 자료와 처리 범위

사용자 요청으로 MX Dual 센서 gain, PNU 1 m/3 m 및 NIAS 실측 타프 반사도 표를 내장합니다. 센서 gain은 기본 잠금이며 필요할 때 편집을 활성화합니다. 작은 PNU 타프 ID는 `PNU_s_3`, `PNU_s_36`, `PNU_s_56`입니다. 내장값이 모든 센서나 다른 재질의 타프에 유효한 것은 아닙니다. 해당 장비·타프와 일치하는지 확인하세요.

방사보정 → 센서 gain 1회 → 최근접 실측 Ed(5초 이하, 보간·외삽 없음) → 타프 ELC 순서를 유지합니다. 포화와 정합 실패 기준을 완화하지 않습니다. 계산 완료와 과학적 품질 승인은 별개입니다. 정사화·모자이크 후처리는 외부 Metashape, BRDF는 별도 작업입니다.

원영상·회차별 Ed·ROI·반사도 결과·개인 경로·인증 정보는 배포에 포함하지 않습니다. 업데이트는 앱 코드를 교체하며 기존 연구 결과를 삭제하지 않습니다.

검증 범위는 [VALIDATION.md](VALIDATION.md), 유지보수는 [MAINTENANCE.md](MAINTENANCE.md)를 참고하세요.
