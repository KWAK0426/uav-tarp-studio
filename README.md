# UAV Tarp Studio

Windows x64 데스크톱 프로그램입니다. 현재 지원 센서는 **MicaSense RedEdge-MX Dual native 10밴드**입니다.

## 시작

1. 배포 ZIP 전체를 쓰기 가능한 로컬 폴더에 풉니다.
2. **UAV_Studio.exe**를 실행합니다. 기존 Python·라이브러리·GDAL/PROJ·ExifTool 동작을 검사합니다.
3. 호환 환경은 재사용합니다. Python 라이브러리가 정상이고 ExifTool만 부족하면 그 도구만 앱 전용 위치에 설치합니다. 호환 환경이 없으면 별도 환경을 준비합니다. 다른 프로그램의 기존 환경은 수정하지 않습니다.
4. 한 날짜·한 회차의 **원영상 폴더**를 선택하고 `원영상 자동 점검`을 누릅니다. 촬영일·누락·중복과 처리 대상을 확인한 뒤 시작합니다.
5. 실측 Ed·센서 gain·타프 반사도 자료를 연결합니다. `관련 실측 자료 찾기`는 사용자가 지정한 폴더에서 CSV 형식에 맞는 후보를 찾습니다. 형식이 맞아도 해당 장비·날짜·타프에 유효한지는 확인해야 합니다.
6. 타프가 보이는 기준·독립 검증 촬영을 고르고, native 타프 경계·trim·전선/그림자 제외·포화를 검토합니다. `다음 단계 진행`과 앱 내부 Codex 도우미가 진행을 안내합니다.
7. 방사보정 → 센서 교정 → 실측 Ed 정규화 → ELC 계수 준비 → 검토·적용 승인 → native Float32 타프 반사도 TIFF 순서로 처리합니다.

원영상에는 타프 실측 반사도·외부 Ed 관측·별도 센서 교정값이 모두 들어 있지 않습니다. 누락 자료나 승인을 만들어 채우지 않습니다. 단계별 과학 검토가 필요한 부분은 사용자가 확인합니다.

타프 반사도 이후 기하보정·정사화·모자이크는 **외부 Metashape**에서 진행합니다. BRDF는 별도 앱의 범위입니다. 이 프로그램은 임의 센서나 모든 촬영 조건을 지원한다고 가정하지 않습니다.

## Codex

`Codex 준비·연결`을 누르면 기존 실행 파일을 찾습니다. 없으면 공식 OpenAI 배포본을 내려받아 SHA256을 검증합니다. 앱 안에서 본인 ChatGPT 계정으로 로그인합니다. 모델 목록과 사용 한도는 그 계정에 따르며, 로그인만으로 실제 추론 성공을 판정하지 않습니다.

로컬 영상 처리는 Codex 연결 없이도 동작합니다. Codex에 질문을 보낼 때는 전송할 내용을 확인할 수 있습니다. 영상·CSV 원문은 자동 첨부하지 않으며, 로그·개인 경로는 기본적으로 첨부하지 않습니다. 인증은 별도 앱 영역의 OS 자격 증명 저장소를 사용합니다. [공식 Codex App Server](https://learn.chatgpt.com/docs/app-server), [인증](https://learn.chatgpt.com/docs/auth).

## 인터넷·업데이트

`인터넷 연결·업데이트 확인` → `인터넷 연결·새 버전 확인` → `다운로드·검사` → `적용·다시 시작` 순서입니다. 앱 실행만으로 GitHub를 조회하거나 자료를 업로드하지 않습니다. 라이브러리/Codex를 처음 설치할 때는 인터넷이 필요합니다.

- 저장소: https://github.com/KWAK0426/uav-tarp-studio
- `updates/downloads`: 받은 패키지
- `updates/staging`: 압축·해시·환경 검증 중인 새 버전
- `updates/backups`: 이전 활성 버전 기록
- `versions`: 설치된 앱 버전. 업데이트가 기존 버전을 삭제하지 않습니다.
- `settings`: 이 PC의 환경 선택·프로젝트 연결 기록. 배포/업데이트 파일에 포함하지 않습니다.

처리·편집 중에는 업데이트 적용을 막습니다. 새 버전 검사가 실패하면 현재 버전을 유지합니다. 문제 발생 시 `이전_버전_복원.bat`으로 직전 버전으로 돌아갈 수 있습니다. 원영상과 프로젝트·결과 폴더는 업데이트 대상이 아닙니다.

## 데이터 비공개

GitHub에는 앱 코드·설치/업데이트 파일만 공개합니다. **원영상, 실측 Ed, 타프 실측 자료, ROI, 계수, 보정 결과, 계정 정보, 개인 경로, 실제 로그는 업로드하지 않습니다.** 배포는 명시된 소스 파일 목록으로만 만들며, 작업 폴더 전체를 압축하지 않습니다. 템플릿 CSV에는 실제 측정값이 없습니다.
