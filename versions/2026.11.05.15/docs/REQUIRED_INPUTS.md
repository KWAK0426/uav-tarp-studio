# GENERAL 필수 입력

## 1. 핵심 ELC

모든 외부 원자료는 결과 폴더 밖에서 사용자가 직접 선택합니다. 경로만 연결하며 파일을 이동·재명명하지 않습니다. 이 에디션은 ELC 반사도 산출까지만 제공합니다. GPS는 태양각 기록용 선택 자료이며 필수 입력이 아닙니다.

| 재료 | 형식·확인 사항 |
|---|---|
| native Raw DN | RedEdge-MX Dual 원본 UInt16 TIFF, EXIF/XMP 보존. `IMG_0001_1.tif`처럼 촬영별 suffix 1~10이 완전해야 함. 이미 방사·Ed·반사도 보정된 영상은 원본 대용 불가 |
| retained-shot CSV | UTF-8 CSV의 정확한 열 이름 `shot`. 한 행에 `IMG_0001` 같은 촬영번호 하나. 빈 행·중복·임의 번호 금지. GPS 대신 사용자가 명시적으로 등록한 처리 대상 |
| 타프 실측 반사도 | `templates/tarp_reflectance.csv` 형식. `key`는 ROI tarp ID와 일치, `use_for_fit`은 1/0. B01~B10은 비율 단위의 실측값 |
| 센서 gain | `templates/sensor_gain.csv` 형식의 `band,gain`. 실제 파장 순서의 band 1~10, 유한한 양수. 본인 장비에 유효한 근거 필요. 빈 값이나 근거 없는 1.0으로 우회 금지 |
| 실측 Ed | `templates/Ed.csv` 형식. `datetime_kst`와 실제 10파장 열. 시각은 `YYYY-MM-DD HH:MM:SS[.소수]`, KST. 방사보정 값과의 물리 단위 일관성 확인 |
| 기준·독립 검증 후보 | 등록 대상 안의 실제 타프 영상 최소 2촬영. 각 밴드에서 반사도가 서로 다른 유효 타프 최소 2개. 기준 영상의 적합용 ROI와 다른 촬영의 검증 ROI 역할 구분 |

대상 CSV 예시 구조입니다. 번호는 형식 예시일 뿐이며 실제 스캔 결과로 선택해야 합니다.

```csv
shot
IMG_0001
IMG_0002
```

1. Raw는 평면 또는 임의 이름의 재귀 하위 폴더에 둘 수 있습니다. `SET/000/001` 구조로 맞출 필요가 없습니다.
2. 전체 스캔에서 중복 촬영번호/밴드, 부분·빈 밴드를 확인합니다. 오류 영상을 조용히 버리거나 먼저 찾은 파일을 자동 채택하지 않습니다.
3. 사용자가 처리 대상을 등록한 뒤 그 부분집합에서 타프 후보를 저장합니다. 후보 선택은 전체 스캔 결과의 자동 일괄 처리 승인이 아닙니다.

타프·Ed 양식은 헤더만, gain 양식은 빈 값입니다. 관측자료·과거 교정·승인 이력은 제공하지 않습니다. 타프 36%를 비율 36으로 넣지 않습니다. RAMSES 원시 스펙트럼은 검토된 변환을 거쳐 Ed CSV로 준비하며, 확장자 변경이나 실측 파장 선택을 SRF 적분으로 설명하지 않습니다.

## 02에서 위치 확인용 모자이크 준비

1. **직접:** `① 현재 회차 Photos 폴더`에 Metashape에서 내보낸 현재 회차의 정사보정된 MX Dual 10밴드 Panel Photos를 선택합니다. 원영상 폴더를 넣는 단계가 아닙니다.
2. 모자이크가 없으면 **Photos로 위치 확인용 모자이크 생성·연결**을 누릅니다. 등록한 촬영번호와 일치하는 Photos의 좌표·밴드를 검사하고, 기존 RGB 합성 방식으로 긴 변 최대 4096화소의 위치 확인용 영상을 만듭니다. **생성과 경로 연결은 자동**이며 진행 중 중지할 수 있습니다. 기존 모자이크가 있으면 생성 없이 아래 경로에 지정합니다.
3. **직접:** 사용한 타프 ID를 지정하고 **모자이크에서 타프 위치 지정 · 겹치는 영상 확인**을 누릅니다. 확대·이동·밝기 조절 후 타프 위치를 지정하고 겹치는 영상만 검토·확정합니다.

생성물은 프로젝트의 `Tarp_Location/Location_Mosaic_<실행시각>_<고유번호>`에 저장됩니다. 원본 Photos를 변경하지 않고 사용한 파일·크기·수정시각·합성 방법을 기록합니다. 생성한 RGB 영상은 타프 위치를 찾는 용도이며 반사도 산출·포화 검사·최종 원영상 ROI 승인 자료가 아닙니다. 원영상만 있다면 Metashape 정사보정·Photos 내보내기가 먼저 필요합니다.

## 2. 파장과 시간

### Ed 원자료를 폴더로 정리하기

시작 화면 또는 프로젝트 상단의 **Ed 원자료 → CSV**를 사용합니다. Codex 연결 없이 로컬에서 실행됩니다.

1. **직접 선택:** RAMSES `.dat` 원자료 폴더와 결과 저장 폴더. 하위 폴더까지 읽습니다.
2. **직접 확인:** 장비가 기록한 원자료 시간대(한국시간 `Asia/Seoul` 또는 `UTC`). 드론 원영상의 EXIF 시간대와 별개입니다.
3. **선택 사항:** 필요한 시작·종료 시각을 한국시간 `YYYY-MM-DD HH:MM:SS`로 모두 입력합니다. 둘 다 비우면 전체 기간을 정리합니다. 범위 양 끝을 포함합니다.
4. **자동 처리:** `폴더 점검 · 날짜별 CSV 생성`을 누르면 날짜별 폴더에 시간순 10밴드 CSV를 저장합니다. 기존 측정 파장 중 가장 가까운 값을 사용하며 시간 보간·평균·외삽이나 SRF 적분은 하지 않습니다.
5. **직접 확인:** 결과 표의 날짜·측정 수·시작·종료 시각을 확인합니다. 프로젝트에서 열었다면 같은 날짜 행을 선택하고 `선택 날짜 CSV를 현재 회차에 연결`을 누릅니다. 시작 화면에서 만들었다면 프로젝트를 연 뒤 생성된 파일을 `실측 Ed CSV`에 지정합니다.

정리 결과는 `Ed_Import_<실행시각>_<고유번호>/<측정날짜>/Ed_<측정날짜>_10band.csv`입니다. 재실행 시 기존 결과를 덮어쓰지 않습니다. `date_index.csv`, 원본 파일별 해시와 사용·제외 사유가 있는 `source_audit.csv`, 시간대·시간 범위·변환 방법·코드 및 출력 해시가 있는 `manifest.json`도 보존합니다.

동일 파일 사본은 한 번만 사용하고 방사휘도(sr 단위)는 Ed에서 제외합니다. 같은 측정 시각에 서로 다른 자료가 있거나 자료 형식·Ed 값에 문제가 있으면 임의 선택 없이 CSV 생성을 보류하고 원인과 파일 목록을 남깁니다. 해당 자료를 확인하거나 필요한 측정 시간 범위를 지정하여 다시 실행하세요. CSV 생성·연결은 촬영 시각과의 매칭 통과를 의미하지 않습니다. 기존 최근접 5초 이내·측정 구간 내 매칭 검사를 처리 전에 수행합니다.

| 밴드 | B01 | B02 | B03 | B04 | B05 | B06 | B07 | B08 | B09 | B10 |
|---|---|---|---|---|---|---|---|---|---|---|
| 파장 nm | 444 | 475 | 531 | 560 | 650 | 668 | 705 | 717 | 740 | 842 |

CSV의 B01~B10은 위 실제 파장 순서입니다. **파일 suffix가 곧 이 밴드 순서라는 뜻은 아닙니다.** TIFF의 파장 메타데이터로 대응시킵니다. 메타데이터가 누락되면 추정하지 말고 중단합니다. RedEdge-P·임의 센서 지원 계약이 아닙니다.

1. 원본 EXIF 촬영시각의 UTC/KST 선택을 실제 메타데이터로 확인합니다. KST 설정 이름은 `Asia/Seoul`입니다.
2. 기준·대상 영상은 최근접 실측 Ed와 5초 이하로 매칭되어야 합니다. 보간·평균·외삽하지 않으며 실측 범위 밖이나 시간차 초과는 누락으로 남깁니다.
3. GPS가 없어도 EXIF 촬영시각과 Ed 정규화를 사용합니다. 태양 천정각·방위각은 빈 값/`unavailable`이며 가짜 좌표·각도를 넣지 않습니다.

## 3. 선택 GPS와 경로 점검

| 항목 | 용도·확인 사항 |
|---|---|
| 실제 GPS TXT/CSV | 태양각 기록용만. 촬영번호·실제 좌표와 좌표계 확인. `shot` 대상 CSV를 대체하지 않음 |
| GPS 없음 | EXIF 촬영시각·실측 Ed로 ELC 진행. 태양각은 빈 값/`unavailable` 유지 |
| ExifTool | 새 전용 환경은 13.07 이상 요구. 긴 Windows 경로는 사전 검사하며 구버전이면 새 환경 또는 짧은 루트 필요 |

한글 경로의 메타데이터 복사는 UTF-8 인자 파일 방식과 제한시간을 사용합니다. 문자 인코딩 처리와 긴 경로 지원은 별개이므로 [범위·제한](KNOWN_LIMITS.md)을 함께 확인합니다. Photos·모자이크·DEM·AOI 마스크를 준비하는 절차는 이 패키지의 입력 안내가 아닙니다.

관측일은 원영상 폴더 경로의 날짜를 자동 입력합니다(YYYY-MM-DD, YYYYMMDD, YYMMDD). 자동 점검 후 EXIF 촬영일을 한국시간으로 확인해 적용합니다. 날짜 자동 입력을 끄면 직접 수정할 수 있으며, EXIF와 다른 날짜로 프로젝트를 생성할 수 없습니다.
