## 2026.11.05.15 타프 세트와 팝업 위치

`PNU_s`는 1 m 검정·회색·흰색 3장 세트입니다. `PNU_s, PNU_s_56`은 세트에 흰색 1장을 추가한 총 4장입니다. 추가 개체는 `PNU_s_56__2`로 구분해 별도 ROI를 보존하며 원래 `PNU_s_56` 실측표를 적용합니다. 같은 재질의 여러 장을 독립 검증의 서로 다른 타프 종류로 중복 계산하지 않습니다. 입력 아래에 펼쳐진 ID와 총 장수를 표시합니다.

스튜디오에서 새로 여는 Tk 보조 창은 중첩된 창을 포함해 스튜디오 본창 가운데에 표시합니다. 사용자가 이동한 창을 다시 표시할 때는 위치를 강제로 되돌리지 않습니다.

## 2026.11.05.14 Ed 폴더 자동 연결

01 자료 연결의 «원자료 폴더 → 자동 연결»에서 RAMSES 폴더를 선택하면 기존 변환기로 하위 .dat를 읽고 프로젝트 Ed 폴더에 날짜별 CSV를 새로 저장한다. 표시된 Ed 시간대(기본 Asia/Seoul=KST, 변경 가능)를 적용하며 현재 촬영일 CSV만 자동 연결·저장한다. 진행률과 현재 단계 예상 시간을 표시한다. 원자료 오류·날짜 불일치·CSV 변경은 연결을 차단하고 이전 Ed 연결을 유지한다. 이미 만든 CSV는 «CSV 선택»으로 연결한다. 최근접 실측 5초 검사와 보간·외삽 금지는 유지된다.

상위 배포 폴더의 `UAV_Studio.exe`로 시작합니다. 이 폴더는 버전별 앱 코드입니다. 사용자 안내와 업데이트 절차는 배포 루트의 README.md / MAINTENANCE.md를 확인하세요.

현재 범위: RedEdge-MX Dual native 10밴드 → 방사·센서·실측 Ed → 검토한 타프 ELC 반사도. 기하보정·모자이크는 외부 Metashape, BRDF는 별도 앱입니다.

`docs/`의 기존 GENERAL 문서는 처리 단계·입력 형식의 참고자료입니다. 이전 설치·Codex 설명보다 현재 배포 루트 문서가 우선합니다.

PNU 3 m: PNU_03/PNU_36/PNU_56. PNU 1 m: PNU_s_3/PNU_s_36/PNU_s_56. 농과원: NIAS_2.5/NIAS_20/NIAS_30/NIAS_50. 총 10종이며 모든 밴드 실측값과 기존 fit/validation 역할을 유지한다. 숫자는 명목 반사도(%)이고 계산에는 실측 밴드값을 사용한다. PNU_s는 2026-10-26 측정 및 99% 기준 백판 가정을 유지한다. 기존 1m_Black/Gray/White 프로젝트는 별도 호환 CSV로 계속 연결되며, 새 라이브러리로 변경할 때는 ROI 이름도 검토한다. 공개 GitHub 미게시.


## 2026.11.03.6 위치 확인과 타프 검증 우선

01 스캔·등록은 파일 목록 검사다. 02에서 모자이크와 해당 회차 정사영상 Photos를 연결하고 사용한 타프 ID를 선택한다. 기존 확대·이동·밝기/스트레치·타프별 영역·겹침 검색·영상 체크박스 도구로 위치와 후보를 확정한다. 전체 원영상 목록은 후보로 자동 표시하지 않는다. 03의 native ROI·trim·그림자 제외·정렬·전체 경계 포화 검사 후 선택 영상만 보정·ELC·독립 검증한다. 05의 «검증 결과 승인 · 전체 처리 허용»은 최소 두 유효 기준/독립 검증 타프와 10밴드 검사, 오차 보고서 사용자 승인을 요구한다. 오차 수치에 임의 자동 합격 한계를 도입하지 않는다. 승인 전 전체 방사/Ed/반사도 실행은 backend에서도 차단한다. 입력·ROI·Photos·모자이크·교정값·검증 결과가 바뀌면 승인 근거가 무효다. 기존 원본·ROI·결과는 삭제하지 않는다. 연구용 위치 도구를 재사용했고 공개 GitHub에는 업로드하지 않았다.

## 2026.11.05.8 부분 밴드 완료 결과 연결

05 상단에서 이미 생성한 부분 밴드 실행 폴더를 연결할 수 있다. 현재 날짜·회차·원영상·Ed·gain·실측 타프·선택 영상·승인 ROI와 실행 출처가 일치해야 한다. 출력 범위, 제외 파장, 독립 검증 오차와 반사도 폴더/보고서 버튼을 표시한다. 결과를 열 때 출처와 파일 해시를 다시 검사하며 TIFF 전체 유효 화소의 계수 역산식도 확인한다. 같은 내용의 내장 교정표는 앱 버전 경로만 바뀌어도 연결 가능하다.

이는 이미 완료한 실행의 읽기 전용 연결이다. 새 부분 밴드 자동 계산이나 전체 촬영분 승인을 추가하지 않는다. 기존 ROI/프로젝트 설정을 변경하거나 영상을 다시 만들지 않는다. 연결된 프로젝트의 다음 단계 버튼은 완료 결과 확인으로 이동한다. 일반 10밴드 계산은 기존 검사를 유지한다.
