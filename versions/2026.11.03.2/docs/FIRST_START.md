# GENERAL 최초 설정

## 1. 환경 설치와 확인

1. `00_INSTALL.bat` → `02_CHECK.bat` → 합성 검사 → `01_START.bat` 순서로 진행합니다. 합성 검사 명령은 [Codex 인수인계](CODEX_HANDOFF.md)를 참조합니다.
2. 패키지의 `environment.yml`은 ExifTool 13.07 이상을 요구합니다. 기본 전용 위치는 `%LOCALAPPDATA%\ELCStudioShare\runtime-20261026`이며 base Python을 수정하지 않습니다. 기존 환경은 자동 갱신되지 않으므로 실제 ExifTool 버전을 확인합니다.
3. Conda를 찾지 못하면 `ELC_CONDA_EXE`에 실제 `conda.exe` 절대 경로를 지정합니다. 다른 전용 환경 위치는 설치 전에 `ELC_STUDIO_ENV`로 정합니다.
4. `.local/doctor.json`의 imports·ExifTool·해시 오류를 확인합니다. 결과 저장 드라이브 공간은 별도로 점검합니다. 정책 차단은 전역 해제하지 말고 해당 PC 관리자와 확인합니다.

긴 Windows 경로에서 구버전 ExifTool이 차단되면 새 전용 환경을 설치하거나 입력·결과 루트를 짧게 지정합니다. 원본을 임의 이동하지 않습니다. [경로 제한](KNOWN_LIMITS.md)을 확인하세요. 첫 설치·합성 검사·빈 화면 확인만으로 실자료 처리를 시작하지 않습니다. 구버전의 짧은 경로 재검사가 새 환경 전체 통과를 뜻하지 않으며, 검증 사실은 [VALIDATION.md](../VALIDATION.md)를 기준으로 합니다.

## 2. 새 프로젝트 창

`01_START.bat`은 기억된 GENERAL 프로젝트가 없으면 생성 창을 엽니다. 추가 생성은 `03_NEW_PROJECT.bat`입니다.

| 화면 항목 | 입력 규칙 |
|---|---|
| `관측 날짜` | 실제 촬영일. `YYYY-MM-DD` 형식, 예: `2026-06-10`. 연도 고정 없음 |
| `현장 이름 (폴더명)` | 예: `현장A`, `현장B`. 문자·숫자·밑줄·하이픈 사용. 경로 구분자·공백·Windows 예약 이름 제외 |
| `촬영 회차` | 같은 날 촬영한 묶음. 예: `1st`, `2nd`, `오전`. 현장 이름과 같은 이름 규칙 |
| `프로젝트·결과 저장 폴더` | **원영상 위치가 아님**. 여유 공간이 있는 결과 저장 루트. 오른쪽 `폴더 선택...` 사용 |

첫 설정창도 원본 스튜디오의 테마·폰트·버튼을 그대로 사용합니다. 항목을 채우면 `생성될 작업 폴더`에 실제 경로가 표시됩니다. 누락·잘못된 날짜·이미 있는 프로젝트는 안내가 표시되고 생성 버튼이 비활성화됩니다.

`프로젝트 만들고 시작`을 누르면 아래 설정을 만들고 스튜디오를 엽니다. **영상 처리는 시작하지 않으며**, 다음 `01 자료 연결` 화면에서 원영상·타프 실측값·센서 gain·Ed 자료를 지정합니다.

```text
작업루트/현장/YYYY-MM-DD/세션/project.json
```

이 JSON 자체가 핵심 전처리 설정입니다. `general.project_root`는 위 세션 폴더의 절대 경로입니다. 임의 관측일·회차를 대입하거나 이전 Share 프로젝트를 복사해 승인 상태를 이어받지 않습니다. 같은 프로젝트가 있으면 덮어쓰지 말고 기존 파일을 엽니다.

이미 작업한 자료는 왼쪽 `기존 프로젝트 열기...`에서 해당 회차의 `project.json`을 선택합니다. 취소하면 설정 파일을 생성하지 않습니다.

## 3. 첫 화면: `ELC 반사도`

1. **01 자료 연결**에서 `원영상 루트`, `처리 대상 촬영 CSV`, 타프 실측 CSV, gain CSV, Ed CSV를 직접 선택합니다. 외부 원자료는 결과 폴더 밖에 두고 이동시키지 않습니다.
2. `원영상 스캔`으로 평면·임의 하위 폴더 전체를 확인합니다. 중복·부분 밴드는 해결 후 재검사합니다. 직접 준비한 대상 CSV를 쓰거나, 검토 후 `완전한 촬영분을 대상 목록에 등록`으로 프로젝트 안에 CSV를 생성합니다. 스캔만으로 자동 등록되지 않습니다.
3. **02 원영상 후보**에서 등록 목록 또는 `원영상 파일로 선택`을 사용합니다. 필요한 native 미리보기만 열고 기준·검증에 사용할 부분집합을 골라 `후보 저장`합니다. 이 단계의 선택만으로 기준·ROI가 승인되지 않습니다.
4. **03 타프 ROI·승인**에서 최신 편집기의 ROI·내부 제외 화소·기준/검증 역할을 검토합니다. 파일 저장과 승인은 다릅니다.
5. **04 방사·센서·Ed**, **05 ELC 계수·반사도**로 진행합니다. `1. 자동 보정·계수 준비` 후 승인 대기에서 보고서를 읽고 `2. 계수 확인·반사도 생성`으로 별도 적용 승인합니다.

화면은 ELC 5단계만 제공합니다. 01의 `선택 입력 · 태양각 기록용 GPS`에서 실제 GPS를 선택할 수 있으며, 이는 태양각 기록용일 뿐 ELC 필수 입력이 아닙니다. 공간 분석 탭·추가 분석 버튼이나 Photos·모자이크·DEM 입력은 없습니다.

## 4. 시작 시 확인할 설정

| 항목 | 확인할 값·원칙 |
|---|---|
| 센서 | 실제 파장 메타데이터 기반 MX Dual 10밴드 |
| 처리 범위 | `선택 ELC 영상만 처리`로 기준·독립 검증 후보 우선. 전체 등록 대상 처리는 별도 선택 |
| 작업 수·캐시 | 작업 수 1, 방사보정 중간 캐시 끔으로 시작 |
| 원본 시간대 | UTC / KST(`Asia/Seoul`) 중 실제 EXIF 근거로 선택. 기본 UTC를 무조건 신뢰하지 않음 |
| Ed | `datetime_kst` 실측 CSV의 시간대·단위 확인. 최근접 측정값 5초 이하, 보간·외삽 없음 |
| 선택 GPS | 실제 GPS는 태양각 기록용만. 없어도 촬영시간·Ed 정규화 가능. 태양각은 빈 값/`unavailable`이며 가짜 좌표 금지 |
| gain·타프 | 사용자 장비·현장에 유효한 자료. 빈 양식·과거 타인 값으로 진행 금지 |
| 승인·덮어쓰기 | 미승인에서 시작. 원본과 기존 결과 덮어쓰기 금지 |
| 최종 산출물 | native 밴드별 Float32 ELC TIFF, 10밴드 계수 CSV, ROI·타프 독립 검증 HTML |

생성된 대상 CSV·ROI·보고서는 프로젝트 결과입니다. 외부 원자료 경로를 선택하는 것과 구분합니다. 폴더를 옮기면 절대 경로를 재연결하고 서명·승인을 재검사합니다.
