## 실제 합성 전체 계산

`test_general_e2e.py`는 방사보정·Ed·ELC 단계를 모의 처리하지 않고 실제 ExifTool과 처리기를 실행했습니다.

- 입력: 합성 native UInt16 TIFF 2촬영 × 10밴드. EXIF/XMP는 시험 내부에서 생성했습니다.
- 실제 날짜 메타데이터: 2027-06-10, 세션 flight12. GPS·DEM·Photos·필지 마스크 파일 없음.
- suffix와 실제 파장 순서를 다르게 구성해 파장 대응을 검사했습니다.
- 센서 gain 1.10~1.19와 실측 Ed 비율 1→2를 사용했습니다. 두 번째 촬영 DN도 2배로 구성했습니다.
- 계수 준비 후 `awaiting_review`에서 멈추고, 승인 전 반사도 폴더가 없음을 확인했습니다.
- 알려진 전방계수 a,b를 10밴드에서 회복하고, 승인 후 native 512×384 Float32 반사도 TIFF 20개를 생성했습니다.
- 독립 검증 타프의 반사도 0.6을 허용오차 0.000003 이내로 회복했고 원본 SHA256은 변하지 않았습니다.
- 이 작은 시험의 실행 시간은 약 70초였습니다. 현장 전체 회차의 처리 시간 추정값이 아닙니다.

이 시험은 합성 수치·제어 흐름 검증입니다. 실제 타프 정확도, 구름·그림자·포화·센서 모델의 타당성을 보장하지 않습니다.

## Windows 경로와 ExifTool

기존 ExifTool 12.52가 240자 이상 출력 경로에서 메타데이터를 복사하지 못하는 문제를 확인했습니다.
새 버전은 이런 조합을 TIFF 생성 전에 차단하고, ExifTool 13.07 이상 설치 또는 짧은 결과 루트를 안내합니다.
`environment.yml`은 13.07 이상을 요구합니다. 메타데이터 복사는 UTF-8 인수 입력을 사용합니다.
위 실제 전체 계산은 **기존 12.52 + 짧은 검사 경로**에서 통과했습니다. 새 13.07 이상 환경의 긴 경로 전체 실행은 이 PC에서 별도로 수행하지 않았습니다.
근거: [ExifTool Windows 파일명 안내](https://exiftool.org/exiftool_pod2.html), [WindowsLongPath 옵션](https://exiftool.org/ExifTool.html).

샌드박스에서는 ExifTool DLL 실행이 제한되어 관련 검사는 승인된 일반 실행 환경에서 수행했습니다.
전체 실행 로그·화면은 원래 PC의 별도 검증 폴더에 보관하며, 전달 ZIP에는 합성 TIFF·개인 경로·승인 이력을 넣지 않습니다.
