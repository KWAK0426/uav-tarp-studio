# UAV Tarp Studio 배포 소스

루트 README.md와 MAINTENANCE.md를 먼저 읽습니다. 이 에디션은 Windows native MX Dual 10밴드 타프 반사도까지만 처리합니다. Metashape와 BRDF는 외부 작업입니다.

- 원본과 프로젝트·ROI·계수·완료 결과는 업데이트 대상이 아닙니다.
- 기존 호환 환경을 재사용하며 부족한 구성요소는 앱 전용 경로에 준비합니다. 공유 base 환경을 수정하지 않습니다.
- 앱 내부 Codex는 사용자 계정 로그인과 OS 자격 증명 저장소를 사용합니다. 원영상·실측 CSV를 자동 업로드하지 않습니다.
- 처리기는 검증된 로컬 함수만 호출하며 임의 셸/코드나 과학 승인을 모델 답변으로 실행하지 않습니다.
- 날짜·파장은 원본 메타데이터로 확인합니다. 실측 타프·gain·Ed를 만들어 채우지 않습니다.
- 방사 → 센서 gain 1회 → 최근접 실측 Ed (5초 이하, 보간·외삽 없음) → L=a*rho+b → rho=(L-b)/a 순서를 보존합니다.
- ROI·spatial trim·내부 제외 화소·P05/P95·full-ROI 포화는 구분합니다. 최소 두 유효 타프와 독립 검증을 유지합니다.
- 기준·검증 후보, ROI/마스크, 계수 적용 승인과 원본/설정 서명은 별개입니다. 자동으로 승인 플래그를 바꾸지 않습니다.
- run_tests.py, test_desktop.py, test_general_e2e.py와 실제 실행기를 검사합니다. 합성 계산·실자료 정확도·다른 PC 설치·온라인 Codex 추론을 구분해서 기록합니다.
- 배포는 release-tools/build_release.py의 명시 목록으로만 만들며 실제 데이터·로그·인증·개인 경로를 GitHub에 추가하지 않습니다.
