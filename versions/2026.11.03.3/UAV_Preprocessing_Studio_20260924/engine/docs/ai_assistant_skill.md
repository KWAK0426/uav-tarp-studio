# 이 배포본의 AI 사용

ELC 처리는 AI 연결 없이 가능합니다. 이 PC의 Codex와 협업할 때는 배포 루트의 AGENTS.md와 docs/CODEX_HANDOFF.md를 사용하세요.
앱 내부 AI는 선택 기능이며 외부 Codex 세션과 별개입니다. 자동 로그인·데스크톱 토큰 복사·API 키 공유를 하지 않습니다.
실측값·센서 계수·촬영시간·ROI 승인·계수 확인을 AI가 임의 생성해서 처리를 통과시키지 않습니다.
대량 실행·파일 변경·외부 전송은 사용자 확인 뒤에 수행합니다. 상태·파일 존재·처리 완료와 과학적 품질을 구분합니다.
