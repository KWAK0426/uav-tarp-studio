ELC Studio GENERAL

MX Dual native 10밴드의 ELC 반사도 영상 산출 전용 안내입니다. GPS 없이 처리할 수 있으며, 실제 GPS는 태양각 기록용 선택 입력뿐입니다. 앱 내부 AI 로그인은 필요 없습니다.

처음 시작

  1. 00_INSTALL.bat으로 ExifTool 13.07 이상 전용 환경을 설치하고 02_CHECK.bat으로 확인합니다. 기존 환경은 자동 갱신되지 않으며 base 환경은 변경하지 않습니다.
  2. 합성 검사 후 01_START.bat으로 빈 프로젝트를 엽니다. 추가 생성은 03_NEW_PROJECT.bat입니다.
  3. 실제 ISO 날짜·세션·현장을 입력합니다. 외부 원자료는 직접 선택하며 이동하지 않습니다.
  4. 입력·대상 등록 → native 후보 → ROI·화소 검토와 승인 → 방사·gain 1회·실측 Ed → 계수 검토·적용 승인 순서입니다.

대상은 shot CSV로 등록합니다. 최근접 실측 Ed의 허용 시간차는 5초 이하이며 보간·외삽하지 않습니다. GPS가 없으면 태양각은 빈 값/미제공입니다. 전체 대상 처리는 별도 사용자 선택입니다.

계수 준비는 awaiting_review에서 멈추며 사용자 적용 승인 후 native 밴드별 Float32 ELC TIFF·10밴드 계수 CSV·ROI/타프 독립 검증 HTML을 만듭니다. 공간 분석이나 Photos·모자이크·DEM 입력은 제공하지 않습니다.

한글 경로 메타데이터 복사는 UTF-8 인자 파일과 제한시간을 사용합니다. 구버전 ExifTool의 240자 이상 경로는 래스터 쓰기 전에 차단하며 새 환경 또는 짧은 루트가 필요합니다. 새 런타임 전체 통과를 선언하지 않습니다. 상세 상태는 검증 기록을 확인합니다.
